# Working on NeuroGhost

This is the developer side: running the registry locally, checking schemas and
mappings from the command line, tests, and notes for changing the code, the
meta-model and the website. For what NeuroGhost is, adding schemas, mapping
terms, and how changes land, see the [README](README.md) — and, above all,
**suggestions and feedback are welcome**:
[open an issue](https://github.com/sensein/NeuroGhost/issues/new).

## Set up

```bash
git clone https://github.com/sensein/NeuroGhost.git
cd NeuroGhost
pip install -r requirements.txt
```

## Rebuild the registry and view the site

```bash
python neuro_ghost/pipeline.py --fresh --skip-converters   # registry_schemas/ (+ mappings/) -> data/, ~5 min
python -m http.server 8000                                 # site at http://localhost:8000
```

`pipeline.py` options: `--fresh` (start from an empty graph), `--skip-converters`
(don't download external schemas), `--schemas FILE`, `--bump major|minor|patch`,
`--agent TEXT`.

**Don't commit the `data/` a local rebuild writes** — it's regenerated by the
rebuild after each merge.

## Check a schema

What the submission workflow runs, plus a preview against the registry:

```bash
python neuro_ghost/validate_schema.py registry_schemas/<name>.yml      # valid LinkML (imports fetched)
python scripts/check_duplicate_schema.py registry_schemas/<name>.yml   # not already registered
python neuro_ghost/preview_schema.py registry_schemas/<name>.yml       # shared / same name / new / no description
python neuro_ghost/ingest.py --dry-run --verbose-readable registry_schemas/<name>.yml   # every entity it would create
```

`ingest.py` and `preview_schema.py` also take JSON Schema (`.json`), converted
to LinkML first. A schema's metadata goes in `registry_schemas/<name>_source.yaml`
(see `neuro_ghost/source_metadata.py`); its registry label is its LinkML
`name:`, which also goes in the schema dropdowns of
`.github/workflows/propose_mappings.yml`.

## Mappings from the command line

```bash
pip install sentence-transformers        # only needed for proposing; not in requirements.txt
python neuro_ghost/propose_mappings.py aind bids --kind classes     # writes mappings/<set>.sssom.tsv + .yml
python neuro_ghost/mappings.py validate mappings/<set>.sssom.tsv     # format + references, as the Mapping Check does
```

Format and review rules: [`mappings/README.md`](mappings/README.md).

## MCP server

Lets an AI assistant (Claude Desktop, Cursor, …) query the registry — search
classes, read alignments, diff schemas, translate records. It reads
`data/registry.json` (or the live site's copy).

```bash
python neuro_ghost/mcp_server.py                       # stdio
MCP_TRANSPORT=sse python neuro_ghost/mcp_server.py     # HTTP (SSE)
```

A Claude Desktop configuration example is in the module's docstring.

## Tests

```bash
pytest
```

## Meta-model

`meta_model.yaml` defines the registry's entities and which fields make up
their identity (content hash), so a change affects every entity. After editing
it, regenerate and commit both generated files — CI checks they're in sync:

```bash
./scripts/gen_models.sh                    # schema_registry_utils/models.py
python scripts/gen_metamodel_json.py       # data/metamodel.json (the site's Meta-model tab)
```

Explain the change in the PR: what it does to identity, and whether existing
hashes or ids change.

## Website

`index.html` is the whole site (one file, no build step). Serve it locally
with real data (above) and click through the tabs you touched — including
entities with alignments and mappings — and check the browser console for
errors.

## Workflows

`.github/workflows/` holds the schema submission, rebuild, external-schema
fetch, mapping proposal and Mapping Check workflows. Check edits with
[actionlint](https://github.com/rhysd/actionlint).

## Stack

[LinkML](https://linkml.io/) (schemas), [LadybugDB](https://ladybugdb.com/)
(embedded graph DB used during the build), a static one-file site on GitHub
Pages, GitHub Actions, and [sentence-transformers](https://sbert.net/)
(`all-MiniLM-L6-v2`) for proposing mappings.
